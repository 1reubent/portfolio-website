About Me

I build systems that turn messy data into something usable. Most recently, I redesigned the New Jersey Attorney General's Use-of-Force Database (100k+ records) as Database Technical Lead on Rutgers' MBS externship. We migrated the dataset from Excel into a normalized MySQL schema, and built the Python ETL pipeline and Flask API behind it.

B.S. Computer Science, summa cum laude (Rutgers, 2025), now completing an MBS in Data Analytics & AI. I like owning projects end to end — from schema design to deployment.
